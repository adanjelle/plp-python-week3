
# Grade Reporter & Bug Hunt

This repository contains my Week 3 Python assignment on loops and conditional statements.

- `grade_reporter.py`: Assigns grades to five scores, counts passes and failures, and calculates the average.
- `bug_hunt.py`: Fixes three bugs in a while loop program that calculates the sum of numbers 1 to 5.

The hardest bug to find was the incorrect loop condition because it did not produce an error message. I knew something was wrong when the program returned 10 instead of the expected answer, 15, because it stopped before adding 5.
